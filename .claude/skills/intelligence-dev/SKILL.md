# Intelligence Skill Development Guide

## What a skill is
A Python function in `src/intelligence/skills/` that takes a weekly data snapshot (JSON) as input and returns a list of findings (dicts). Skills are pure data analysis — no LLM calls, no external APIs.

## Skill input: the snapshot
Generated by `src/intelligence/snapshot.py`. Structure:
```json
{
  "report_date": "2025-10-20",
  "period": {"start": "2025-10-13", "end": "2025-10-19"},
  "prior_period": {"start": "2025-10-06", "end": "2025-10-12"},
  "acquisition": { ... },
  "conversion": { ... },
  "contribution": { ... },
  "targets": { ... }
}
```

## Skill output: findings
Each finding is a dict with these required fields:
```python
{
    "severity": "critical" | "warning" | "info",
    "domain": "acquisition" | "conversion" | "contribution",
    "metric": str,          # e.g. "LinkedIn CPL"
    "current_value": float,
    "target_value": float | None,
    "prior_value": float | None,
    "change_pct": float | None,
    "finding": str,         # Human-readable finding sentence
    "action": str,          # Specific recommended action
}
```

## How to build a new skill
1. Run `pytest tests/test_data_integrity.py` first — if any fixture test fails, fix it before proceeding
2. Check the snapshot for available data fields (`python -c "import json; print(json.dumps(json.load(open('outputs/snapshot.json')), indent=2))"`)
3. Use the data-analyst agent to explore the relevant data patterns and validate the numbers you plan to use
4. Write the skill function in `src/intelligence/skills/`
5. Test it: `python -c "from src.intelligence.skills.acquisition import analyze; import json; s = json.load(open('outputs/snapshot.json')); print(json.dumps(analyze(s), indent=2))"`
6. Cross-check: verify that key numbers in the skill output match the ground truth fixtures in `tests/fixtures/known_metrics.json`
7. Use the briefing-reviewer agent to evaluate the output for credibility

## Rules
- Every finding MUST compare to a target or prior period
- Never produce a finding without specific numbers
- Severity thresholds: critical (>20% off target), warning (10-20% off), info (<10% or positive)
- Skills should produce 3-8 findings, not 20. Prioritize what matters this week.
- Use the data-analyst agent to explore data patterns before coding the skill logic
- If a skill's output number doesn't match the known ground truth within ±2%, there's a query bug — do not proceed until resolved
